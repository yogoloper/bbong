# BBONG — Slap Card Game

나이롱뽕을 원작으로 한 모바일 카드 게임. 고유 색상 숫자 타일을 사용해 도박 연상 IP(화투/트럼프 문양)를 제거.

## 결정 사항

| 항목 | 결정 |
|---|---|
| 게임명 | **BBONG** (부제: Slap Card Game) |
| 원작 | 나이롱뽕 |
| 카드 | 숫자 1~12 × 4색 = **48장** (문양 없음, 색상만) |
| 색상 | 4종 (색약 고려 명도/패턴 병행 예정) |
| MVP | AI 대전 싱글 + 광고 (온라인 멀티는 후순위) |
| 판돈 | 구매 가능·**환전 불가** 가상 재화. 2~6인 방, 입장료 100~10000. 세트 1등 winner-takes-all (빚과 별개) |
| 목표 등급 | 전체이용가 (한국 GRAC). 숫자/색 두뇌게임 + 환전불가 → Rummikub(전체이용가) 선례 따름 |
| 엔진 | **Unity (C#)**. 코어 로직은 UnityEngine 비의존 순수 C# 라이브러리로 분리 (TDD + 서버 멀티 재사용) |

## 로드맵

- **Phase 0** 규칙 확정 (`docs/rules.md`) ← ✅ 완료 (v1.0)
- **Phase 1** 코어 엔진 (UnityEngine 비의존 순수 C# 라이브러리: 데이터 모델 + 턴 상태머신 + 족보/점수 판정, TDD) ← 현재 단계
- **Phase 2** AI 봇 (휴리스틱, 난이도 3단)
- **Phase 3** UI/UX (카드 애니메이션, 뽕 인터럽트, "찰싹" 연출/사운드)
- **Phase 4** 메타/수익화 (튜토리얼, 상점, 광고 SDK)
- **Phase 5** (선택) 온라인 멀티 (서버 권위 구조)
- **Phase 6** 출시 (스토어 등록, 비공개 테스트, 심사)

## 리스크

- 규칙 모호성(출처 빈약) → rules.md v1.0으로 확정 완료
- 뽕 인터럽트 UX(비동기 끼어들기) 처리
- **사행성 등급 리스크**: 판돈 베팅+몰아주기 도입. 전체이용가 유지 전제 = **환전 절대 불가** + 도박 연상 IP/표현 제거. 환전 기능 추가 시 불법(게임산업법). GRAC 심사는 건별 판단이라 선례(Rummikub)≠보장.
