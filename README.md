# BBONG — Slap Card Game

나이롱뽕을 원작으로 한 모바일 카드 게임. 고유 색상 숫자 타일을 사용해 도박 연상 IP(화투/트럼프 문양)를 제거.

## 결정 사항

| 항목 | 결정 |
|---|---|
| 게임명 | **BBONG** (부제: Slap Card Game) |
| 원작 | 나이롱뽕 |
| 카드 | 숫자 1~12 × 4색 = **48장** (문양 없음, 색상만) |
| 색상 | 4종 (색약 고려 명도/패턴 병행 예정) |
| MVP | AI 대전 싱글 + 광고 (온라인 멀티는 후순위) |
| 목표 등급 | 전체이용가 (한국 GRAC 자체등급분류) |
| 엔진 | 미정 (Unity/Godot/Flutter 후보) |

## 로드맵

- **Phase 0** 규칙 확정 (`docs/rules.md`) ← 현재 단계
- **Phase 1** 코어 엔진 (데이터 모델 + 턴 상태머신 + 족보/점수 판정, TDD)
- **Phase 2** AI 봇 (휴리스틱, 난이도 3단)
- **Phase 3** UI/UX (카드 애니메이션, 뽕 인터럽트, "찰싹" 연출/사운드)
- **Phase 4** 메타/수익화 (튜토리얼, 상점, 광고 SDK)
- **Phase 5** (선택) 온라인 멀티 (서버 권위 구조)
- **Phase 6** 출시 (스토어 등록, 비공개 테스트, 심사)

## 리스크

- 규칙 모호성(출처 빈약) → rules.md로 확정 필수 (최대 리스크)
