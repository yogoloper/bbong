# BBONG (뽕) — 게임 소개 및 설명 문서

## 게임 제목 및 한 줄 소개

**BBONG (뽕)** — 같은 숫자 카드를 모아 "뽕!"을 외치는 한국식 카드 게임을,
서버 권위 실시간 온라인 멀티플레이로 즐기는 웹/모바일 게임입니다.

## 게임 방법

### 목표

숫자 카드(1~12, 4색 48장)로 판마다 **빚(점수)을 가장 적게 쌓는 것**이 목표입니다.
5라운드 1게임이 끝났을 때 누적 빚이 가장 적은 사람이 우승합니다.

### 진행 (핵심 루프)

- 전원 5장으로 시작, 자기 턴에 **1장 뽑고 1장 버립니다** (손패 5장 유지).
- **뽕**: 다른 사람이 버린 카드와 같은 숫자 2장을 손에 들고 있으면, 5초 안에 "뽕!"을
  선언해 3장을 내려놓습니다 (내려놓은 카드는 0점 처리, 손패가 영구히 줄어듭니다).
- **자연뽕**: 내 손에 같은 숫자 3장이 모이면 즉시 내려놓을 수 있습니다.
- **족보**: 드로우 직후 6장이 족보(총통·또이또이·스트레이트·10이하·66이상)를 이루면
  선언 즉시 판이 끝나고 큰 감점(이득)을 받습니다.
- **스톱**: 뽕을 한 상태에서 남은 2장의 합이 10 이하면 "스톱"으로 라운드를 끝낼 수 있습니다.
  내 손합이 뽕한 사람들 중 **유일하게 가장 낮아야 성공**(동점도 실패)이고, 성공하면
  **(10 − 손합)만큼 빚을 청산**합니다(예: 합 3이면 −7점). 실패하면 "스톱 바가지" —
  선언자가 손합+30을 물고, 먹인 승자는 0점입니다.
- **쌍 공개**: 손패가 정확히 2장 동수가 되면 그 좌석의 카드 뒷면이 **붉게 표시**되어
  전원에게 공개됩니다 — "뽕 바가지 주의" 신호입니다.
- **뽕 바가지**: 붉은 경고에도 같은 숫자를 버려 상대가 손을 털면(2차 뽕) 버린 사람이
  손합+30 벌점을 뭅니다. 경고할 틈 없이 터지는 뽕+자연뽕 콤보(**자연뽕 바가지**)는 +50입니다.
  바가지를 당한 사람이 다음 라운드의 선이 됩니다(첫 라운드 선은 무작위).

### 조작

- 마우스 클릭(모바일은 터치)만 사용합니다.
- 내 차례가 되면 화면 하단 안내 문구가 할 일을 알려줍니다 — 예: "버릴 카드를 클릭하세요. (5)"
- **모든 행동에는 5초 제한**이 있고, 시간이 지나면 자동으로 진행됩니다(방금 뽑은 카드 자동 버림 등).
- 게임 중 이탈하거나 한 판 내내 응답이 없으면 그 자리는 **AI 봇이 이어받아** 게임이 끊기지 않습니다.

### 종료 조건

한 라운드는 ① 족보 완성 ② 뽕으로 손패 소진 ③ 스톱 선언 ④ 더미 소진 시 끝나고,
**5라운드 종료 시 누적 빚 최저인 사람이 우승**합니다.

### 게임 모드

- **튜토리얼**: 7개 레슨으로 규칙을 처음부터 배우는 인터랙티브 교습(모든 유저 동일 시나리오)
- **연습 모드**: AI 봇 2~6인전 (서버 불필요, 난이도 선택 가능)
- **친구와 함께**: 6자리 초대코드로 방을 만들어 2~6인 실시간 멀티플레이.
  방장이 봇을 추가해 자리를 채울 수 있습니다.
- **맞춤게임**: 인원(2~6)과 입장료를 고르고 "시작하기" 한 번으로 **빠른매칭** —
  같은 조건의 방에 자동 배정되고, 정원이 차면 5초 카운트다운 후 자동 시작합니다.
  우승자가 총상금(입장료×인원)을 모두 가져가는 winner-takes-all 포인트전입니다
  (포인트는 게임 내 재화로, 환전은 불가합니다).

### 온라인 공통 규칙

- 모든 행동 5초 제한(초과 시 자동 진행), 게임 중 이탈/무응답 자리는 **AI 봇이 이어받아**
  게임이 끊기지 않습니다. 이탈했던 유저는 재접속하면 자기 자리를 되찾습니다.

## 실행 방법

### 웹에서 바로 플레이 (설치 불필요)

아래 링크를 브라우저에서 열면 바로 실행됩니다 (데스크톱 권장, 모바일은 가로 화면):

**플레이 링크**: https://yogoloper.github.io/bbong/?server=https://bbong.fly.dev

1. "게스트로 시작"으로 로그인합니다 (가입 불필요).
2. 메인 로비에서 **튜토리얼 → 연습 → 친구와 함께/맞춤게임** 순으로 즐겨보세요.
3. 친구와 함께: 한 명이 방을 만들어 6자리 초대코드를 공유하고, 나머지가 코드로 입장한 뒤
   방장이 시작합니다. 맞춤게임: 조건 선택 후 "시작하기"만 누르면 자동 매칭됩니다.

### 소스에서 실행 (개발용)

- 저장소: https://github.com/yogoloper/bbong
- 클라이언트: Unity 6000.4.10f1로 `client/BbongClient` 열기
- 서버: `docker compose up -d`(PostgreSQL) → `cd server/BbongServer && dotnet run` (.NET 8)
- 자세한 절차는 저장소의 `docs/worklog.md`(빌드/실행 섹션)와 `docs/web-deploy.md` 참고
