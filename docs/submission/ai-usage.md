# BBONG (뽕) — AI 활용 기술 문서

## 1. 사용 AI 도구

| 도구 | 용도 |
|---|---|
| **Claude Code** (Anthropic, Claude 모델 CLI 에이전트) | 기획 정리 → 룰 명세 → 코어 엔진 → 서버 → 클라이언트 → 배포까지 전 개발 과정의 페어 프로그래머 |

개발 전 과정을 Claude Code와의 대화형 세션으로 진행했으며, 커밋 메시지에
`Co-Authored-By: Claude`가 남아 있어 저장소 커밋 기록으로 활용 이력을 확인할 수 있습니다.

## 2. 프로젝트 구조와 AI의 역할

```
core/BbongCore     순수 C# 룰 엔진 — 게임 규칙 전부 (NUnit 테스트 136개)
server/BbongServer ASP.NET Core — 계정/지갑 API + WebSocket 실시간 멀티 (테스트 163개)
client/BbongClient Unity 6 — 코드 생성 UI, 공용 게임 테이블 뷰(GameTableView)
tools/             봇 시뮬레이터(BotSim)·부하 시뮬레이터(BbongLoadSim)
scripts/           Playwright 자동 플레이 테스트·100인 매칭 폭풍 테스트
```

- **룰 명세 우선**: 구두로 설명한 전통 놀이 규칙을 AI와 문답으로 `docs/rules.md`(확정 룰 명세)로
  정리한 뒤, 이 문서를 단일 기준으로 코어를 구현했습니다. 애매한 규칙(또이또이 구성, 바가지 점수,
  공동 1등 절사 등)은 AI가 엣지 케이스를 제시하고 사람이 확정하는 방식으로 좁혔습니다.
- **TDD**: 코어와 서버는 Red(실패 테스트) → Green(구현) → Refactor 사이클로 AI가 테스트를
  먼저 작성하고 구현했습니다. 총 299개 자동화 테스트.
- **서버 권위 멀티**: 좌석별 개인화 스냅샷(RoundView) + 이벤트 프로토콜 설계, 단일 소비 루프로
  선착순 뽕 레이스 차단, 5초 턴 타이머·이탈 시 봇 대체 등 온라인 룰을 AI와 설계·구현했습니다.
- **UI 단일 틀**: 연습/멀티가 공용 `GameTableView` 하나를 사용하도록 AI가 리팩터링해
  모드 간 UI·문구 불일치를 구조적으로 제거했습니다.
- **디버깅**: Unity Editor.log를 AI가 직접 분석해 레이아웃 버그(WebGL 손패 뭉개짐 등)의
  원인을 코드 수준에서 특정하고 수정했습니다.
- **판돈 멀티(맞춤게임)**: 유저별 지갑 락(PostgreSQL advisory lock)으로 동시 인출 레이스를
  차단하고, 입장 에스크로 → 이탈 몰수 → 우승자 정산(winner-takes-all)까지 AI가 TDD로
  구현했습니다. 빠른매칭은 대기 10초 후 사람처럼 보이는 봇이 랜덤 간격으로 자리를 채우고,
  정원이 차면 5초 카운트다운 후 자동 시작합니다.
- **자동 플레이 테스트**: Playwright가 실제 웹 빌드를 좌표 클릭으로 조작해 로그인→게임 진행을
  검증하고(4종 시나리오), WebSocket 봇 100명이 랜덤 조건으로 매칭돼 실게임을 완주하며
  지갑 정합·완주율을 검증하는 폭풍 테스트를 AI가 작성·운영했습니다(100/100 완주, 이상 0건 —
  규칙 개편 후에도 배포 서버에서 재검증). "봇 턴에 손패를 난타"하는 퍼징으로 실제 레이스
  버그를 재현→수정→회귀 검증한 사례도 있습니다.
- **게임 히스토리(운영 기록)**: 모든 온라인 게임의 딜 시점 손패 스냅샷·드로우·버림·뽕·족보·
  스톱·정산 이벤트를 PostgreSQL(관계형 3테이블 + JSONB 페이로드)에 기록하고, 참여자 본인이
  조회하는 API(/me/games, /games/{id}/events)를 갖춰 CS·디버깅에 대비했습니다.
- **배포 자동화**: WebGL용 브라우저 WebSocket 브리지(jslib), GitHub Pages Actions 배포,
  fly.io 서버 컨테이너화, Unity 배치(CLI) 빌드 파이프라인까지 AI가 작성해
  "코드 수정 → 빌드 → 배포 → 배포본 자동 검증"을 무인으로 수행했습니다.

## 3. 게임 내 AI (봇)

- `core/BbongCore/Ai/Bot.cs` — 난이도 3종(Easy/Normal/Hard) 휴리스틱 봇.
  - 버릴 카드: 높은 숫자 / 페어 보존 / 쓸모도 평가(쌍·연속·저점 지향).
  - 스톱: 손합 구간별 **확률 밴드**로 결정해 플레이 다양성을 확보(무조건 스톱 편중 제거).
  - **카드 카운팅**: 공개 정보(버림 더미·나간 패·내 손)만으로 상대가 나를 언더컷할 확률을
    조합 계산해, 바가지 위험이 높으면 스톱을 참습니다.
  - **순위 전략(Hard)**: 누적 점수상 1등이면 빨리 손을 털어 리드를 굳히고, 뒤지면 스톱 대신
    두 번 뽕(상대 박)을 노려 상대 빚을 유도합니다.
- 라운드 종료 사유 분포를 측정하는 시뮬레이터(`tools/BotSim`, 난이도별 3,000라운드)로
  튜닝 전후를 정량 비교하며 밸런스를 조정했습니다(순수 스톱 종료 58%→43%).
- 온라인 게임 중 이탈/무응답 자리는 이 봇이 이어받고, 맞춤게임의 매칭 대기 자리도
  사람처럼 보이는 Hard 봇이 채워 게임이 항상 성립합니다.

## 4. 주요 프롬프트/지시 예시

### 프로젝트 킥오프 프롬프트 (초기 세션 요지 재구성)

프로젝트를 시작한 첫 세션들의 지시를 요지로 복원한 것입니다:

> "한국 전통 카드 놀이 '나이롱뽕'을 온라인 게임으로 만들려고 해. 내가 아는 규칙을 설명할 테니
> 애매한 부분은 네가 엣지 케이스를 질문해서 함께 확정하고, 확정된 규칙을 `docs/rules.md`
> 명세로 먼저 작성하자. 그 명세를 단일 기준으로 삼아 구현해."
>
> "구조는 셋으로 나눠: ① 게임 규칙 전부를 담는 순수 C# 코어(클라·서버가 공유),
> ② Unity 클라이언트, ③ 서버 권위 온라인 멀티를 위한 ASP.NET Core 서버.
> 최종 목표는 플레이스토어/앱스토어 출시야."
>
> "개발은 TDD로: 실패하는 테스트를 먼저 쓰고(Red), 통과시키고(Green), 정리해(Refactor).
> 버그 수정도 재현 테스트부터. 그리고 규칙·문구·UI는 모든 모드에서 반드시 동일해야 해."

### 개발 중 대표 지시 (실제 세션 원문 요지)

- "Red → Green → Refactor 순서를 지켜 구현해줘. 버그 수정도 재현 테스트부터." (전역 지침)
- "게임 판 UI를 통일하고 멘트도 통일해야 해. 하나의 틀로 연습/친구/일반 게임이 참여자만
  다르게 돌아가야 해." → 공용 GameTableView 추출 리팩터링
- "5초 안에 카드를 내려놓지 않으면 자동으로 진행되는 규칙, 그리고 이탈한 유저는 봇이
  대체해서 한 게임이 끝날 때까지 진행되게 해줘." → 턴 타이머 + 봇 대체 구현
- "족보 선언 문구가 어디서는 '스트레이트', 어디서는 'Straight'로 나오면 안 돼." →
  코어에 표시명 단일 출처(MeldNames) 신설
- "친구방을 웹으로 배포해서 GitHub Pages로 플레이할 수 있게 해줘." → WebGL WebSocket
  브리지 + 쿼리 토큰 인증 + Pages/fly.io 배포 구성
- "맞춤게임은 시작하기 하나로 — 조건 맞는 방이 없으면 방장이 돼서 대기하고, 10초 뒤부터
  봇을 실제 유저인 것처럼 입장시켜. 정원이 차면 5초 카운트다운 후 시작." → 빠른매칭 +
  위장 봇 충원 + 자동 시작 구현
- "100명의 유저가 랜덤 조건으로 매칭해서 게임을 즐기는 시나리오를 테스트하고, 이상한 점이
  없어질 때까지 수정-배포-재시험을 반복해줘." → 폭풍 테스트 하네스 작성, 매칭 레이스
  버그 발견·수정 후 배포본에서 100/100 무결 확인
- "봇이 버려진 패를 카운팅해서 바가지를 쓰지 않게 하고, Hard는 순위를 고려해 1등이면 빨리
  털고 뒤지면 바가지를 유도하게 해줘." → 카드 카운팅 + 순위 전략 구현
- "손패 2장이 같으면 전원에게 알리고, 예고 없이 터지는 뽕+자연뽕 콤보는 벌점을 키워줘.
  규칙이 바뀌었으니 플레이어블 튜토리얼도 전반적으로 재구성해줘." → 쌍 공개(붉은 뒷면) UI,
  자연뽕 바가지(+50), 7개 레슨 튜토리얼 재구성
