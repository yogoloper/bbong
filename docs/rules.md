# BBONG 규칙 명세 (v1.0)

> 원작 나이롱뽕(화투 러미 계열) 기반. 본 문서는 게임 로직 단일 진실 공급원(SSOT)입니다.
> 코드/테스트는 이 명세를 따릅니다.
> v1.0: 제작자 보유 룰 기준으로 전면 확정. 잔여 모호점은 `❓OPEN` 표기.

---

## 0. 게임 목표

러미 계열. **"빚 탕감"** 모델입니다. 손패를 먼저 털어 빚을 줄이는 것이 목표입니다.
고정 5판 진행 후 빚을 가장 많이 탕감한(가장 낮은) 유저가 승리합니다.

## 1. 구성 요소

- **덱**: 숫자 1~12, 각 숫자 4색(빨강/파랑/초록/노랑) 1장씩 = **48장**.
  - 색 = 사본 식별용. 같은 숫자 4장이 색만 다릅니다. 문양 없음(도박 IP 제거).
  - 족보 판정에 색 일치 요건 없습니다.
- **인원**: 2~5명 (MVP: 플레이어 1 + AI 2~4). 3~5명 권장.
- **카드 점수값**: 숫자 그대로 (1~12).

## 2. 셋업

1. 48장 셔플합니다.
2. **전원 5장씩** 나눕니다. (선/비선 구분 없이 동일)
3. 남은 카드 = 뒷면 **바닥 더미(draw pile)**. 버림 더미(discard pile)는 **비어 있는 상태로 시작**합니다.
4. 선부터 진행합니다. 방향은 좌석 순서로 고정합니다.
   - **다음 판 선**: 직전 판을 **끝낸(종료시킨) 게이머**가 다음 판의 선이 됩니다(족보 선언자 / 두 번 뽕 완성자 / 스톱 선언자). 게임 첫 판은 좌석 0번이 선입니다.
   - **바가지 예외**: 스톱 바가지·뽕 바가지가 나면 **바가지를 당한 게이머**(스톱 선언자 / 마지막 버린 게이머)가 다음 판 선이 됩니다.
5. **첫 오픈**: 셋업 시 카드를 미리 오픈하지 않습니다. **선이 첫 턴에 카드를 버리는 순간** 버림 더미 첫 장이 생깁니다.

## 3. 턴 진행 (핵심 루프)

기본 손패 = **5장** 유지. 한 턴의 순서입니다.
1. **드로우**: 바닥 더미에서 1장 가져옴 → 손패 6장.
2. **족보 체크**: 6장으로 족보(§5) 성립 시 선언 → 판 종료(§5).
3. **버림**: 필요없는 카드 1장을 버림 더미로 버림 → 손패 5장 복귀.
4. 다음 플레이어로 턴을 넘깁니다.

**턴 제한 시간**: 자기 턴에 **5초** 안에 카드를 버려야 합니다. 시간 초과 시 **방금 드로우한 카드를 자동으로 버립니다**(기본값, 설정 변경 가능). 실시간 타이머라 클라/서버가 처리하며, 코어 엔진은 자동 버림 동작만 적용합니다.

종료 조건: 한 게이머가 **손패를 모두 소진**하면 그 판이 끝납니다(§8).

**바닥 더미 소진 시**: 버림 더미와 **나간 패(뽕/자연뽕 고정 패)를 포함해 테이블 위 카드 전부**를 다시 셔플해 새 바닥 더미로 사용합니다(버림 더미는 빈 상태로 재시작). 나간 패의 "0점"은 낸 사람 손 점수에서 빠진다는 뜻일 뿐, 카드는 순환에 복귀합니다. **재셔플은 최대 2회**(`maxReshuffles`)까지. **2회 재셔플 후에도 또 소진되면 → 그 판 강제 종료**, 전원 남은 손패 합으로 점수 등록(별도 승자 없음). 다음 선은 마지막 드로우 시도자.

## 4. 카드를 버리는(터는) 방법

### 4-1. 뽕 (인터럽트)

- 누군가 카드를 버릴 때, 버려진 카드와 **같은 숫자 2장**을 손에 든 게이머는 차례와 무관하게 **"뽕!"**을 외치며 그 2장을 내려놓습니다.
- **처리**:
  1. 버려진 1장 + 손의 2장 = 같은 숫자 3장을 **'나간 패'로 고정**(점수 0 — 낸 사람 손 점수에서 제외. 재셔플 시 덱으로 복귀 §3).
  2. 그 후 손패에서 **1장 더 버립니다**.
  3. 결과: 손패 **5장 → 2장**으로 줄어듭니다.
- **턴 재개**: 뽕 선언자의 **다음 플레이어**부터.
  - 예) 1→2→3→4→5 순서에서 4번이 버린 카드를 2번이 뽕하면, 다음은 **3번**부터 진행합니다.
- **뽕 입력 타이머**: 한 게이머가 카드를 버린 뒤 다음 게이머가 턴을 이어받기 전까지 **2초**의 창이 열립니다. 2초 안에 "뽕!"을 외쳐야 성립하며, 타임아웃 시 뽕 포기로 처리합니다.
- **같은 숫자 연속/동시 뽕 = 구조적 불가**: 같은 숫자는 4장뿐입니다. 뽕으로 3장이 고정되면 1장만 남아 같은 숫자 2장을 다시 못 모읍니다. → 특정 숫자에 대한 뽕 선언자는 항상 단일입니다.

### 4-2. 자연뽕

- **자기 턴에만** 가능합니다.
- 드로우로 6장이 된 상태에서 **같은 숫자 3장**을 손에 들고 있으면, 선언 없이 그 3장을 **'나간 패'로 내려놓습니다**(점수 0, 손에서 제거).
- 그 후 필요없는 카드 1장을 버리고 다음 게이머로 턴을 넘깁니다.

### 4-3. 두 번 뽕으로 게임 종료

- 뽕/자연뽕으로 손패가 2장으로 줄어든 게이머가, **다른 숫자로 한 번 더 뽕**을 하면 손패 2장을 내려놓으며 **손 소진 → 판 종료**합니다.
- 예) 5장 → (1차 뽕) 2장 내려놓고 1장 버림 = 2장 남음 → (2차 뽕) 남은 2장을 내려놓으며 판 종료.
- 서로 다른 숫자에 대한 뽕이므로 §4-1의 "같은 숫자 구조적 불가"와 모순되지 않습니다.

## 5. 족보 (6장 완성 = 즉시 판 종료, 드로우 직후 선언)

| 족보 | 구성 | 점수(빚) |
|---|---|---|
| **또이또이** | 같은 숫자 2장씩 3쌍(2+2+2) 또는 같은 숫자 3장씩 2벌(3+3) | **0** (빚 0 탕감) |
| **스트레이트** | 연속 숫자 6장. 1\~6 ~ 7\~12 범위. (예: 10·11·12·1·2·3 형태 wrap 불가) | **-(6장 합)** (합만큼 탕감) |
| **10이하** | 6장 합계 ≤ 10 | **-100** |
| **66이상** | 6장 합계 ≥ 66 | **-100** |
| **총통** | 같은 숫자 4장 (잔여 카드 무관) | **-100** |

- 점수는 빚 기준입니다. 음수 = 탕감(유리), 양수 = 빚 증가(불리).
- **총통은 예외**: 다른 족보가 6장(드로우 직후) 시점 판정인 것과 달리, **5장 또는 6장 상태에서 같은 숫자 4장**이면 성립합니다. 즉 드로우 전에도 선언 가능합니다.
- 족보 2종 이상 동시 성립 시 가장 유리한(가장 많이 탕감되는) 1개만 적용합니다.

확정:
- 스트레이트 wrap(11·12·1) 불허 / 색 무관.
- 총통 4장 성립, 잔여 카드(1~2장) 제약 없음.

## 6. 스톱 (저점 종료)

- **조건**: 뽕(또는 자연뽕)을 한 게이머가 **2명 이상**일 때, 뽕을 한 게이머만 스톱을 외칠 수 있습니다.
- 손패 **2장의 합이 10 이하**일 때 자기 턴에 **"스톱"**을 선언 → 판 즉시 종료, 정산합니다.
- **스톱 한도는 기본 10**이며, **설정으로 변경 가능하게 구현**합니다(예: 5).
- **성공 판정**: 선언자의 손합보다 **적거나 같은** 뽕 게이머가 없어야 성공입니다(동점도 실패).
- **성공 정산**: 선언자는 **(한도 10 − 손합)만큼 빚을 청산**합니다(음수 점수 — 예: 합 3이면 −7,
  빚 0이었다면 −7점 획득). 나머지 게이머는 자기 남은 손패 합을 빚으로 집니다.
- **실패(스톱 바가지)**: 먹인 승자(최저 손합 뽕 게이머, 동점 포함)는 **0점**,
  당한 선언자는 **손패 합 + 30점 빚**, 나머지 게이머는 **자기 남은 손패 합**을 집니다.

## 7. 뽕 바가지

- **조건 ①(2차 뽕)**: 이미 뽕을 한 게이머가 있는 상태에서, 다른 게이머가 카드를 버려 그 뽕한 게이머가 **또 뽕(2차 뽕)을 하며 판이 종료**되는 경우(§4-3).
- **조건 ②(뽕+자연뽕)**: 뽕 직후 남은 3장이 전부 같은 숫자면, 추가 버림 대신 그 3장을 **자연뽕으로 내려놓아 손을 비우고 판을 즉시 종료**할 수 있습니다. 예: 손패 2,2,5,5,5에서 상대가 버린 2를 뽕 → 남은 5,5,5 자연뽕.
- **정산**: 바가지 먹인 승자(손 턴 게이머)는 **0점**, 당한 게이머(마지막 버린 사람)는
  **자기 손패 합 + 20점 빚**, 나머지 게이머는 **자기 남은 손패 합**을 빚으로 집니다.
  바가지를 당한 게이머가 다음 판 선입니다.

## 8. 점수 정산 & 판/게임 종료

> **용어**: **판(round)** = 한 번의 손패 대결. **게임(game)** = 고정 5판 묶음(누적 빚으로 1등 가림 + 판돈 정산). "세트"라는 표현은 쓰지 않고 **게임 = 5판**으로 통일합니다.

### 판 종료 트리거
1. **6장 족보 완성 선언** (§5)
2. **한 유저가 뽕을 두 번** 하여 손패 소진 (§4-3)
3. **뽕한 유저 2명 이상**인 상태에서 한 유저가 **스톱 선언** (§6)
4. **바닥 더미 재셔플 2회 후 소진** → 강제 종료, 전원 손패 합 정산 (§3)

### 점수 정산 (빚 모델)
- **손을 턴 게이머**(판을 끝낸 자):
  - 뽕/자연뽕 또는 또이또이로 끝낸 경우 → **빚 0** (탕감 없음).
  - 다른 족보(스트레이트/10이하/66이상/총통)로 끝낸 경우 → **해당 점수만큼 빚 탕감**(마이너스).
- **나머지 게이머**: 손에 남은 카드 숫자 합 = 그 판의 빚(+).
- 뽕/자연뽕으로 나간 패는 0점으로 손패 합에서 제외합니다.
- 스톱 바가지·뽕 바가지 판: 먹인 승자 0점 / 당한 게이머 손패 합+벌칙(+30/+20) / 나머지 손패 합(§6, §7).

### 게임 종료
- **고정 5판** = 1게임.
- 5판 누적 빚이 **가장 낮은(가장 많이 탕감한)** 게이머가 최종 승리합니다(음수 가능). 빚이 가장 많은 게이머가 꼴찌입니다.
- 멀티(§9)에서는 **게임 종료 시 방을 폭파**(해체)합니다. 같은 방에서 다음 게임을 이어가지 않습니다.

## 9. 판돈 (메타 — 게임 내 빚과 별개)

> ⚠️ 컴플라이언스: 판돈은 **구매 가능하나 현금 환전이 절대 불가능한** 가상 재화입니다. 환전 기능을 두면 사행성 게임물로 불법이 됩니다(게임산업법). 전체이용가 유지의 전제 조건입니다. (Rummikub 선례: 전체이용가 + 구매코인 베팅 + 환전불가)

### 9-1. 방 생성

- 방장이 방을 만들 때 **참가 인원**과 **판돈**을 정합니다.
- **인원**: 2명 ~ 6명.
- **판돈(입장료)**: `100 / 500 / 1000 / 5000 / 10000` 중 선택.
- 참가자는 입장 시 판돈만큼의 재화를 걸어야 합니다. 보유 재화가 부족하면 입장 불가입니다.

### 9-2. 판돈 정산

- 판돈은 **게임 내 빚(§7~8) 점수와 완전히 별개**입니다. 서로 영향을 주지 않습니다.
- 게임(5판) 종료 후, **빚을 가장 많이 탕감한(누적 빚 최저) 1등**이 **참가자 전원의 판돈을 모두 가져갑니다**(winner-takes-all). 정산 후 **방 폭파**.
- 1등 획득액 = `판돈 × 참가 인원`. 1등 본인 판돈 포함(즉 순이익 = `판돈 × (인원 − 1)`).
- 나머지 게이머는 건 판돈을 잃습니다.

### 9-3. 공동 1등 (동점)

- 누적 빚 최저값이 여러 명이면 **상금(총 판돈)을 인원수로 균등 분배**합니다.
  - 예) 2명 공동 1등 → 총 판돈을 1/2씩.
- 나눗셈 나머지는 **절사**합니다(소수점 이하 버림, 잔여분은 소멸). 예) 총 판돈 500을 3명 공동 1등 → 166씩.

### 9-4. 이탈 / 무응답 (AFK)

- **대기실에서 방장 퇴장**: 방은 폭파되지 않고 **다음 입장자에게 방장을 위임**합니다(맞춤게임·친구방 공통).
  마지막 1명까지 나가면 그때 방이 닫힙니다.

- **이탈 판정** 두 가지:
  - 연결 끊김.
  - **무응답(AFK)**: 연결은 유지되나 **한 판(라운드)이 끝날 때까지 직접 입력이 한 번도 없이**
    턴 타이머 자동 버림으로만 진행된 경우 → 판 종료 시점에 강퇴.
- 이탈/강퇴 시 (모든 모드 공통 — 원활한 게임 진행 목적):
  1. **AI(컴퓨터)가 해당 자리를 이어받아 플레이**합니다(게임 중단 없음).
  2. 이탈 유저는 **즉시 패배 처리**(1등 후보에서 제외).
  3. **판돈 반환 불가**(몰수). 남은 인원 중 우승자가 상금(총 판돈)을 그대로 가져갑니다.
- **친구방(무료)**: 봇 대체는 동일하게 적용하되 판돈이 없으므로 정산 영향 없음.

### 용어 주의 (도박 연상 회피)
- 코드/내부 문서: `stake`(판돈) 대신 입장료 의미의 중립 표기 권장. UI 노출 문구는 도박 연상("판돈"·"베팅") 최소화.
